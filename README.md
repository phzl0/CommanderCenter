# Command Center
Dashboard privado de inteligência e gestão profissional. MVP em desenvolvimento local, sem configuração de deploy.

Stack: FastAPI, PostgreSQL, SQLAlchemy, Alembic, Pandas, React, TypeScript e Docker.

Consulte docs/plano-mvp.md para o escopo aprovado. As instruções completas de execução serão adicionadas com as etapas do MVP.
